# 第一次看排球

先掌握以下幾件事，就能看懂比分與基本攻防。以下依 [TPVL 入門頁](https://tpvl.tw/about/volleyball-101)整理，查核日 2026-11-22；[來源 S008](../sources/S008-volleyball-101.md)。

| 新手問題 | 基本概念 |
|---|---|
| 場上有幾人？ | 每隊同時六人，分前排與後排。這不是整支球隊的人數。 |
| 如何得分？ | 每個回合產生一分；例如對手未能合法處理球，會讓另一方得分。 |
| 如何贏一局？ | 前四局目標 25 分，第五局目標 15 分；都須至少領先兩分。 |
| 如何贏整場？ | 先贏三局，也就是五局三勝。 |
| 為何接球後還要舉球？ | 一隊通常以接球、舉球、攻擊合作將球送回；一般有三次擊球機會，攔網觸球不列入這三次。 |
| 為何球員換位置？ | 接發球隊贏得回合並取得發球權時，需順時針輪轉。 |

## 小練習

假設前四局之一打成 24:24，25:24 還不能結束，26:24 才符合領先兩分。第五局若 14:14，也需繼續到分差兩分。這些是教學假設，不是實際賽果。
