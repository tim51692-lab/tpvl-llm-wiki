# TPVL 球迷入門 LLM Wiki

> 本專案為課堂成果。學校、學號、系級及姓名請依課程要求填入作業平台。

## 1. 主題與簡介

以台灣職業排球聯盟 TPVL 為主題，幫助初次接觸的球迷認識球隊、球員、教練、規則與觀賽資訊。先討論用途與範圍，再建立 AGENT.md，依 LLM Wiki 方式維護原始來源、知識頁、索引與日誌。

共完成 11 篇 ingest：兩份規章 PDF 與九個官網內容頁。同站頁面仍屬同一發布機構，不宣稱為不同機構的獨立查證。資料查核狀態為 2026-11-22。

## 4. Loop / graph 設計

討論目標 → 取得資料 → 查核來源、日期與條文 → 整合 Wiki → 跨頁一致性檢查 → 查詢 Wiki → 整理教學重點 → 產生 HTML → 檢查版面與操作 → 修正及複查。

- 每篇來源重複查核、摘要、整合與更新索引。
- 證據不足或矛盾時回到來源，未能釐清則記錄待確認。
- 教學內容缺資料時先更新 Wiki，再修改簡報。
- 版面與互動有問題時修正相關頁面，再次檢查。

這樣設計可讓知識持續累積，也避免不確定資訊直接進入教學成果。

## 5. 一次實際執行結果

規章整理時發現單場名單人數條文有不同寫法，保留位置並記錄待確認。官網學歷欄未明寫畢業狀態，因此不自行寫成畢業結論。

簡報第一輪檢查發現第 12 頁說明侵入註腳區，調整間距後複查通過。另檢查桌面與手機版面、翻頁、三題測驗，以及 25:24、26:24、14:15、14:16 的比分情境。原本本機版的 38 個本地引用目標存在；本 GitHub 版本將 Wiki 閱讀入口改成專案內的 Markdown 網址。

## 6. 反思

本次最常需要回頭確認的是來源查核與知識整理，例如隊名更新不同步、職稱欄位不一致，以及學歷未明示畢業。這是本次觀察，不代表長期錯誤率統計。

因此把主文、附件、版本、日期與欄位核對移到摘要寫入 Wiki 之前，並更新 AGENT.md，減少不明確內容被重複使用。無法確認的內容保持缺口，不靠猜測補齊。

版面問題則顯示，未來可先完成最密集的表格頁並檢查，再擴展成整份簡報。這是本次實作提出的後續改善方向。
