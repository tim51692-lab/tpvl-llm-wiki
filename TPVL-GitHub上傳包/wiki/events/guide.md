# 主題日與觀賽資訊怎麼找？

## 已確認的購票方式

TPVL [購票資訊](https://tpvl.tw/tickets)說明，門票由各主場球隊分別販售，票價、座位與開賣時間以各隊公告為準。先找比賽主隊，再從官方入口前往售票頁。〔[S010](../sources/S010-tickets.md)，2026-11-22 查核〕

場館可能不只一處，例如[台鋼天鷹](../teams/tsg-skyhawks.md)頁面列臺南、高雄兩處主場，出發前須確認當場地點。

## 本輪的主題日查核結果

截至 2026-11-22，本輪查閱聯盟首頁、最新消息列表、各隊頁及購票頁，並以站內限定搜尋「主題日」「2026」，**尚未取得具體近期主題日的可引用公告**。這是本次查核範圍內的資料缺口，不代表各隊沒有活動，也不宣稱已搜尋完整網站或全部社群。

目前可確認的是購票入口，不能把一般賽事、售票訊息或頁面上的待公布提示直接轉成主題日活動。

## 下一步從哪裡找？

聯盟[購票資訊](https://tpvl.tw/tickets)另連到各隊官方網站。本輪僅記錄入口，尚未逐一查核這些外部網站：

- [臺北伊斯特](https://eastpower.tw)
- [桃園隊](https://ty-leopards-vb.com)
- [新竹可利工程師](https://collieengvolley.com)
- [臺中連莊](https://winstreak-volleyball.com)
- [台鋼天鷹](https://www.tsgskyhawks.com)

取得具體公告後，才建立活動頁，記錄活動名、球隊、活動時間、場館、參加條件、狀態、原公告與查核日期。
