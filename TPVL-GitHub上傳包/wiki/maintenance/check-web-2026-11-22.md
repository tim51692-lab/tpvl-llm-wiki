# 官網資料整合與引用檢查

## 本次實際範圍

新增 S003–S011 共九篇：五個球隊頁、規則入門、具名球員介紹、購票資訊及賽季公告。與原兩份 PDF 合計十一篇。另讀首頁、聯盟介紹及消息列表作導航與核對，不重複計入篇數。

已為九篇來源保存 HTTP 200 HTML 回應、擷取文字、擷取時間與 SHA-256。原網站的互動、圖片、外部售票與雲端附件沒有全部下載，不宣稱完整鏡像。

## 實際檢查與處理

| 節點 | 觀察到的問題或結果 | 本輪處理 |
|---|---|---|
| 來源取得 | 一般執行環境無法建立下載連線 | 經使用者允許後保存頁面副本，九個正式來源均取得 HTTP 200 回應 |
| 名稱與時間 | 工具讀取及直接下載的不同頁面，桃園隊名及部分戰績不同步 | 比對當次直接下載文字，保存快照；隊名採球隊主標題但保留差異，未推定更名日期；不引用即時戰績 |
| 人員分類 | 教練團區混列總經理、領隊、球團職員、防護員；簡偉倫職稱欄位不一致 | 依具體職稱整理教練表；另標執行教練與總教練分類的差異 |
| 名單狀態 | 已顯示球員卡片，也有新賽季名單待公布提示 | 五隊卡片數為 13、16、16、14、16；保留提示，不宣稱為完整正式註冊名單 |
| 學歷證據 | 高偉誠人物頁列學歷，但未明寫畢業狀態 | 人物頁維持學歷欄措辭，不把畢業當成已驗證結論 |
| 規則適用 | 簡化入門頁不能涵蓋競賽規程所有例外 | 先教人數與計分等基本概念，精細判決保留完整條文查核需求 |
| 活動查找 | 讀取聯盟首頁、消息列表、隊頁、購票頁並限定站內搜尋，未找到具體近期主題日依據 | 記錄搜尋範圍與資料缺口，不把未查得寫成沒有活動；外部球隊站入口另列，未宣稱已逐站搜尋 |
| 引用日期 | 多數常設頁面未標發布日，賽季公告有明確 2026-10-10 日期 | 引用清單分開記錄發布日期與取用日期，不用版權年份補日期 |

## 本輪 workflow 的實際調整

在「取得資料」之後、「摘要與寫入」之前加入頁面主標題、內文職稱、賽季、發布日期與直接下載快照的對讀。已更新 AGENT.md。

這讓隊名、分類與更新時間的問題先被標記，再進入 Wiki；後續製作簡報時沿用已查核頁面。更新既有聯盟與競賽頁，移除已補齊資料仍寫待補的敘述，讓新來源真正改變既有知識。

## 可用於反思的觀察

本輪最需要判斷的節點是「將網頁欄位轉成知識」：拿到官方網頁仍要辨識職稱、時間、學歷狀態與空白提示。這些主要是來源歧義與證據限制，不能假裝都是生成後才發生的錯誤。尚未製作簡報，因此不填寫簡報檢查通過或整份作業已完成。

交付前檔案、連結、快照雜湊及事實對照的執行結果，另存於[驗證紀錄](verify-web-2026-11-22.json)。
