# TPVL 球迷入門 Wiki

給剛接觸台灣職業排球聯盟的球迷：認識球隊與人物，看懂比賽，再安排觀賽。

目前已整合 **11 篇資料：2 份 PDF 與 9 個官網內容頁**，已達至少五篇的數量要求；仍有主題日與畢業狀態等資料缺口。這是可閱讀的 Markdown Wiki，尚未對外發布。另已完成[17 頁教學 HTML 簡報](teaching/intro.md)。

- **有幾隊？**本次查核各隊頁列五隊，詳細名稱與來源見[總覽](teams/index.md)。
- **球員畢業於哪裡？**已以[高偉誠](people/kao-wei-cheng.md)示範學歷查詢；官網未明寫畢業狀態，不能直接改成畢業結論。
- **有哪些近期主題日？**本輪尚未確認具體公告，詳見[查核範圍與官方入口](events/guide.md)；不能據此說沒有活動。
