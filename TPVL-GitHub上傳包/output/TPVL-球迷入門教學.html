聯盟

把賽事組織起來

安排賽程、制定賽務規範，

球團

經營球隊與主場

組成教練團與球員陣容，
提供球迷互動與主場服務。

Taiwan Professional Volleyball League共同目標：發展職業排球、連結地方球迷、培育人才。

局數比分與聯盟積分

一場打完後，還會產生用於聯盟紀錄的積分。

單場局數比分勝隊積分敗隊積分
3 : 0 ／ 3 : 130
3 : 221
例：甲隊以 3:2 贏球甲隊拿 2 點聯盟積分，乙隊拿 1 點。此為教學假設，與單局內的得分不同。

三題小測驗

選一個答案，立即查看說明。

1. 本簡報整理的 2026-27 賽季有幾隊？

答案：5 隊，依本次 Wiki 查核的五個球隊頁。

2. 前四局之一打成 25:24，這一局結束了嗎？

答案：繼續。要至少領先兩分，例如 26:24。

3. 現場票價與開賣時間，應以哪裡為準？

答案：主場球隊公告，售票與活動資料要核對日期。
