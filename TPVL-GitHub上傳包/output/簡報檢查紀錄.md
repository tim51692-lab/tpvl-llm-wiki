- 保留桃園隊名稱差異、簡偉倫職稱差異、學歷未明確畢業及主題日缺資料等限制。
- 排名條文尚有疑義，因此只教積分分配，不產生未確認的完整排名規則。
- 沒有為填補版面而新增球員學歷、活動或即時戰績；沒有另外查網路資料繞過 Wiki。

## 實際發現與修正

1. 第一輪桌面檢查發現第 12 頁積分頁的下方說明侵入註腳區約 11.65 像素。
2. 減少積分表的列間距及範例區上方間距，保留內容與可讀字級。
3. 複查通過；最後一輪桌面、手機均無偵測到的內容／註腳重疊及水平溢出。
4. 手機五隊表格的長隊名與場館斷行不佳，重新分配欄寬；將頁尾檔名代稱改為「Wiki 延伸閱讀」。
5. 手機換頁增加下一畫面重設捲動位置，減少片段網址與先前捲動位置影響新頁的情況。

這次的版面問題實際發生在「產生 HTML 後的畫面檢查」節點。對未來流程的建議是：完成表格最密集的一頁後，先檢查內容高度與註腳距離，再套用到整份簡報。這是本次檢查所得的調整方向，不冒稱已完成長期多輪比較。
