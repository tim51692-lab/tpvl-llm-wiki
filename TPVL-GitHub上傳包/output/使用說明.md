# TPVL 教學 HTML 簡報使用說明

簡報主題：第一次看 TPVL 就上手。

## 開啟方式

以 Chrome、Edge 等一般瀏覽器開啟同資料夾中的 `TPVL-球迷入門教學.html`。簡報共 17 頁，內容、插畫、樣式與互動皆包含在這一份 HTML 中，不需要安裝套件或啟動伺服器。

- 電腦：用左右方向鍵、上一頁及下一頁按鈕操作；目錄可直接跳頁。
- 手機：可用底部按鈕或左右滑動換頁；較長頁面可以上下捲動閱讀。
- 第 9 頁可練習比分；第 14 頁有三題即時回饋測驗。
- 電腦版有全螢幕與列印按鈕，瀏覽器是否允許全螢幕由環境決定。
- 列印會顯示全部 17 頁，並包含小測驗答案。

## 引用與資料範圍

內容以本專案 Wiki 作為知識來源，適用 2026-27 賽季與 2026-11-22 的資料查核狀態。每頁附 Wiki 延伸閱讀及來源編號，末兩頁列原始資料。學歷、名單、主題日與規則的未確認事項保持原有標記。

簡報本體可離線閱讀。外部官網連結需要網路；本地 Wiki 與 PDF 連結需保留資料夾結構。單獨複製 HTML 不會帶走 Wiki 或 PDF。

## 繳交包

`TPVL-教學簡報與Wiki.zip` 解壓縮後包含：

- `output/TPVL-球迷入門教學.html`：教學簡報。
- `output/TPVL-簡報來源對照.json`：各頁對應的 Wiki、來源編號與輸入檔案雜湊。
- `output/簡報檢查紀錄.md`：本次實際檢查與修正結果。
- `wiki/`：可閱讀的知識庫、來源摘要與維護紀錄。
- `raw/`：PDF 與官網查核快照。
- `AGENT.md`：Wiki 維護規則。

請先解壓縮完整資料夾，再開啟簡報。這是本機成果，尚未發布為公開網站。
